## 📌 Project Overview

Fake news can spread rapidly across online platforms and mislead readers, damage public trust, and create social confusion.  
This project focuses on detecting **Bangla fake news** using Natural Language Processing, classical machine learning models, and a transformer-based deep learning approach.

The system classifies Bangla news articles into two categories:

| Label | Meaning |
|---|---|
| `0` | Fake News |
| `1` | Authentic News |

## ✨ Key Features

- 🧹 Bangla text preprocessing  
- 📊 Exploratory Data Analysis  
- ☁️ Bangla word cloud visualization  
- 🔠 TF-IDF feature extraction  
- 🤖 Multiple machine learning classifiers  
- 🧠 Multilingual BERT-based classification  
- 📈 Accuracy, precision, recall, F1-score evaluation  
- 🧪 Custom Bangla news prediction support  
- 💾 Model saving with Joblib and PyTorch
